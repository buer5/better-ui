## B 站（长）

**标题**

【开源】better-ui：一个 JS 文件，一整套桌面级 UI 组件

**简介**

better-ui 是一套桌面应用风格的 Web UI 组件套件，用它可以拼出控制面板、设置页、仪表盘和 App 外壳。

- 一个 JS 文件就是全部：样式和交互都在里面，零依赖，放进 `<head>` 即可，首屏不闪
- 组件：侧边栏 / 顶部标签导航、列表行、开关、分段控件、下拉选择器（带图标栏和收藏）、行菜单、编辑 / 确认对话框、实时流向图、用量卡片、设置页
- 明暗两套主题，`data-theme` 一行切换，也可以跟随系统
- 窗口 ≥ 1024px 用侧边栏，更窄时自动切到居中的顶部标签
- 附带 `skill/SKILL.md`：给 Claude Code、Codex、OpenCode、WorkBuddy 等 AI 编程工具安装后，它们会按套件的结构直接搭页面，不乱编样式

视频前半段逐个展示组件本身，后半段展示用这些组件拼出的示例应用 Perch（仓库自带的 index.html，一个虚构的家庭服务器控制台）。画面里的组件都是真实页面运行录制的，不是后期做的假 UI。
